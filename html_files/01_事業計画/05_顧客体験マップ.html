05_顧客体験マップ

顧客体験マップ（3パターン）

パターン1：遠方に住むご家族が、親御さんの日々の暮らしを心配しているケース

  • 顧客像： 東京在住の50代女性。旭川市内で一人暮らしをする80代の母親のことが気がかり。母親は最近、外出がおっくうになり、月一回の通院も少し負担に感じている。
  • 利用プラン： 【竹】すこやか充実コース（月額20,000円）
フェーズ お客様の行動・感情 「ぴたっとナース」の接点
1. 認知 娘さんが「旭川 親 病院 付き添い」などで検索し、Instagramで「ぴたっとナース」を発見。「看護師さんがやってるんだ、良さそう」と興味を持つ。 [cite_start]SNSでの発信\<br>「離れて暮らすご家族との結びつき」をテーマにした投稿が目に留まる [cite: 82]。
2. 検討 公式サイトを訪れ、代表の野村さんのプロフィールや事業への想いを読み、信頼感を抱く。料金プランが明瞭な点も安心材料に。 ウェブサイト\<br>代表者の顔と経歴、具体的なプランを提示することで不安を払拭。
3. 初回相談 サイトのフォームから問い合わせ。後日、旭川の母親、東京の娘さん（オンライン参加）、野村さんの三者で面談。母親も「野村さんなら優しそう」と乗り気に。 三者面談\<br>ご本人とご家族、双方の不安をヒアリングし、最適な「竹プラン」を提案。
4. サービス利用 【1回目】 通院サポートを利用。野村さんが診察に同席し、医師の説明を補足してくれたおかげで、母親の理解が深まる。【2回目】 野村さんの提案で、母親が好きだった近所の公園へ散歩に出かける。 [cite_start]専門的サポート\<br>看護師としての知識で、通院の質を向上させる。本人の「やりたい」気持ちを引き出す提案を行う [cite: 178, 187, 191]。
5. 報告・満足 娘さんの元に、その月のサポート内容と母親の楽しそうな写真が添えられた月次レポートが届く。「プロに頼んで本当に良かった」と心から安心する。母親も、外出の良いきっかけができたと喜ぶ。 [cite_start]月次レポート\<br>単なる業務報告ではなく、写真や表情の変化を伝えることで、家族の心のつながりを強める [cite: 56]。

パターン2：ご本人が、将来のために主体的にサービスを探しているケース

  • 顧客像： 旭川市在住の70代男性。一人暮らしで身の回りのことは自分でできるが、複数の科に通院しており、薬の管理や医師とのコミュニケーションに少し不安を感じ始めている。「子供たちには迷惑をかけたくない」が口癖。
  • 利用プラン： 【梅】あんしん基本コース（月額12,000円）
フェーズ お客様の行動・感情 「ぴたっとナース」の接点
1. 認知 かかりつけの病院の待合室に置かれていたパンフレットを見て、「ぴたっとナース」を知る。「看護師の付き添い」という言葉に興味を持つ。 オフラインでの連携\<br>地域の医療機関や薬局にパンフレットを設置。
2. 検討 パンフレットに書かれた電話番号に連絡。「まずは一度、お話だけでも」と無料相談を予約する。 電話対応\<br>丁寧な言葉遣いと、親身な対応で安心感を与える。
3. 初回相談 野村さんが自宅を訪問。自身の病状や不安に思っていることを話すと、専門的な視点で共感してくれたことに安心し、その場で「梅プラン」の利用を決める。 初回アセスメント\<br>サービス利用契約書やアセスメントシートに基づき、丁寧にご本人の状況をヒアリング。
4. サービス利用 月に一度の循環器内科の通院に同行を依頼。野村さんが事前に聞きたいことを整理してくれ、診察時に一緒に医師に質問してくれたおかげで、長年の疑問が解消する。 [cite_start]通院サポート\<br>ただ付き添うだけでなく、ご本人が納得できる医療を受けられるよう、コミュニケーションを支援 [cite: 55]。
5. 報告・満足 サービス後、野村さんから「息子さんにもご報告しておきましょうか？」と提案があり、お願いする。息子さんからも「専門家が見てくれてるなら安心だ」と言われ、肩の荷が下りる。 [cite_start]家族への情報連携\<br>ご本人の許可を得た上で、適切な情報を家族へ共有し、安心の輪を広げる [cite: 56]。

パターン3：単発の特別な目的で、専門サポートを求めているケース

  • 顧客像： 旭川市在住の80代のご夫婦。ご主人が最近大きな病気を経験し、退院したばかり。「子供たちに迷惑をかけないよう、元気なうちに色々準備しておきたい」と考えている。
  • 利用サービス： 専門サポート「もしも」の備えサポート（1回 10,000円〜）
フェーズ お客様の行動・感情 「ぴたっとナース」の接点
1. 認知 地域包括支援センターの職員に相談したところ、「専門家と一緒に整理してくれる、こんなサービスがありますよ」と「ぴたっとナース」を紹介される。 専門機関からの紹介\<br>地域包括支援センターなどとの信頼関係を構築。
2. 検討 ウェブサイトで「もしも」の備えサポートの内容を確認。「エンディングノートは難しそうだけど、これならできそう」と前向きな気持ちになる。 ウェブサイト\<br>専門サポートの内容を具体的に紹介し、顧客の潜在的なニーズを掘り起こす。
3. 初回相談 電話で問い合わせ。野村さんから「不安な気持ちを整理するお手伝いですから、ゆっくり進めましょう」と温かい言葉をかけられ、依頼を決意する。 電話対応\<br>デリケートな相談内容に対し、看護師としての傾聴スキルで対応。
4. サービス利用 全2回の訪問で、野村さんと一緒に緊急連絡先リスト、かかりつけ医やかかりつけ薬局の情報、お薬リストなどをまとめた「安心ファイル」を作成。夫婦の想いも書き留める。 [cite_start]専門サポート\<br>単なる情報整理だけでなく、ご夫婦の想いを引き出す対話を通じて、前向きな「終活」を支援 [cite: 72]。
5. 報告・満足 完成した「安心ファイル」を遠方に住む子供たちに送付。「こんなにしっかり準備してくれてありがとう。すごく安心した」と電話があり、夫婦ともに大きな安堵感に包まれる。 成果物の提供\<br>「安心ファイル」という目に見える形で成果を提供し、高い満足感と家族の安心を実現。

パターン4：従業員の「介護離職」に悩む企業と、その従業員ケース

  • 顧客像： 旭川市内のIT企業と、そこで働く40代の男性従業員。市内で一人暮らしをする父親の通院頻度が増え、男性が仕事を休んで付き添うことが増え、業務に支障が出始めている。
  • 利用プラン： 法人契約による福利厚生サービス（従業員の父親は【竹】すこやか充実コースを利用）
フェーズ お客様の行動・感情 「ぴぴっとナース」の接点
1. 認知 企業の総務部長が、旭川産業創造プラザの紹介で「ぴたっとナース」を知る。「従業員の介護離職防止に繋がるかもしれない」と関心を持つ。 公的機関・企業連携\<br>産業創造プラザや商工会議所などを通じた法人向けPR活動。
2. 検討 総務部長が野村さんに連絡。野村さんが企業を訪問し、従業員の仕事と介護の両立を支援する「福利厚生プラン」を提案。 法人向け提案\<br>介護離職による損失と、福利厚生導入によるメリット（人材定着、生産性向上）を具体的に説明。
3. 初回相談 企業がこの制度を従業員に案内。男性従業員が早速利用を申し出る。野村さんが父親のご自宅を訪問し、サービス内容を説明、契約。 従業員への導入支援\<br>企業と連携し、従業員がスムーズにサービスを利用できるようサポート。
4. サービス利用 月2回の通院を野村さんが代行。男性従業員は仕事を休むことなく、スマホに届く野村さんからの的確な報告で父親の状況をリアルタイムに把握できる。 業務への貢献\<br>従業員が仕事に集中できる環境を創出。専門的な報告で、従業員の精神的負担も軽減。
5. 報告・満足 男性の仕事のパフォーマンスが改善。父親も「息子に気兼ねなく病院に行ける」と満足。企業は優秀な人材の離職を防ぐことができ、三方よしの結果に。 企業価値向上への貢献\<br>「従業員を大切にする企業」としての社会的評価向上にも貢献。

パターン5：退院直後で、在宅生活への復帰に不安があるケース

  • 顧客像： 80代女性。骨折で入院し、退院が決まったが、まだ一人での生活に不安がある。介護保険のサービスが開始されるまでの1ヶ月間、集中的なサポートが必要。
  • 利用プラン： 【松】よくばり安心おまかせコース（最初の1ヶ月間のみ）
フェーズ お客様の行動・感情 「ぴたっとナース」の接点
1. 認知 入院先の病院の退院支援看護師が、介護保険開始までの「つなぎのサービス」として「ぴたっとナース」をご本人とご家族に紹介する。 医療機関との連携\<br>病院の医療連携室や退院支援部署との日頃からの関係構築。
2. 検討 ご家族が「看護師さんが退院直後を支えてくれるなら心強い」と前向きに検討。すぐに野村さんに連絡を取る。 信頼性\<br>医療専門職からの紹介であるため、スムーズに検討段階に進む。
3. 初回相談 退院前カンファレンスに野村さんも参加。病棟看護師やリハビリ担当者から直接情報を引き継ぎ、ご自宅の環境も確認した上で、最適なサポートプランを提案。 多職種連携\<br>医療の専門用語が通じる強みを活かし、病院とのシームレスな連携を実現。
4. サービス利用 退院後の1ヶ月間、週に2〜3回訪問。退院後の初回診察の付き添いや、リハビリの進捗確認、服薬管理、家の中での安全な動き方などを包括的にサポート。 退院後集中ケア\<br>在宅復帰における不安な時期に集中的に関わることで、再入院を防ぎ、在宅生活の基盤を整える。
5. 報告・満足 1ヶ月後、女性はすっかり自宅での生活に自信を取り戻す。ケアマネジャーが作成した介護保険のケアプランにも、野村さんからの情報が活かされ、スムーズに公的サービスへ移行できた。 公的サービスへの橋渡し\<br>自費サービスならではの柔軟な対応で、「制度の狭間」を埋める社会的な役割を果たす。

パターン6：公的サービスを利用しつつ、趣味や生きがいを大切にしたいケース

  • 顧客像： 70代女性。介護保険の訪問介護で身の回りの手伝いはしてもらっているが、週一回のコーラス教室が生きがい。しかし、会場まで一人で行くのが少し不安。「ヘルパーさんは趣味には付き添えない」と言われている。
  • 利用サービス： 単発でのご利用（時間制プラン）を毎週利用
フェーズ お客様の行動・感情 「ぴたっとナース」の接点
1. 認知 担当のケアマネジャーに「コーラスだけが続けられなくて寂しい」と相談したところ、「保険外だけど、こんなサービスなら願いを叶えられますよ」と紹介される。 ケアマネジャーとの連携\<br>地域のケアマネジャーに、公的サービスではカバーできない「＋α」の支援内容を日頃から伝えておく。
2. 検討 「趣味のためだけにお願いするなんて…」と一度はためらうが、「やりたいことを続けるのが一番の健康法ですよ」というケアマネジャーの言葉に後押しされ、電話してみる。 潜在ニーズの掘り起こし\<br>「生活に必須ではないが、QOL（生活の質）向上に不可欠」なニーズに応える。
3. 初回相談 電話口の野村さんの明るい声と、「素敵ですね！ぜひ応援させてください」という言葉に、心が晴れやかになり、毎週の利用を決める。 共感と傾聴\<br>ご本人の「生きがい」を尊重し、肯定する姿勢が信頼につながる。
4. サービス利用 毎週水曜の午後、野村さんがコーラス教室へ付き添う。会場での準備を手伝い、終わるまで待っていてくれる。帰りの車での音楽談義が、新たな楽しみに。 QOLの向上\<br>身体的な介助だけでなく、楽しみや生きがいを共有することで、心の健康をサポート。
5. 報告・満足 コーラスを続けられることで、生活にハリが生まれ、表情も明るくなる。ケアマネジャーも「ぴたっとナースさんにお願いして良かった」と、他の利用者にも紹介したくなる。 口コミの創出\<br>満足度の高いサービスが、地域の専門家からのさらなる紹介という好循環を生み出す。
