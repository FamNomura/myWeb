
# プロジェクトレポート: ぴたっとナース資産Web

## プロジェクト名称

**ぴたっとナース資産Web**

## プロジェクト概要

「ぴたっとナース」プロジェクトに関する事業計画書、サービス利用規約、販促チラシ、プレゼンスライド等の多岐にわたる資産を一元管理・公開するためのポータルサイトプロジェクトです。リポジトリ内のディレクトリ構造を自動解析し、最新のドキュメント一覧をHTMLインデックスとして生成・維持することを目的としています。

## 主要な技術スタック

* **プログラミング言語**: Python 3 (インデックス生成スクリプト), HTML5, CSS3, JavaScript
* **CI/CD・自動化**: GitHub Actions
* **プレゼンテーション**: reveal.js (Webベースのスライド形式資料で使用)

## ディレクトリ構造

```text
myWeb/
├── .github/
│   └── workflows/
│       └── generate-index.yml   # 資産インデックスの自動更新ワークフロー
├── generate_index.py            # フォルダ走査およびindex.html生成スクリプト
├── html_files/                  # 公開資産（HTML, PDF, 画像, 音声）
│   ├── 01_事業計画/              # 事業計画書、収支計画書、ロードマップ等
│   ├── 02_ドキュメント/          # サービス利用規約、契約書、アセスメントシート等
│   ├── 03_チラシ・名刺/          # 営業用チラシ、名刺デザイン案、ウェブ案等
│   ├── 04_プレゼンスライド/      # ビジコン資料、スライド用画像・音声アセット
│   └── 05_作業中/                # 修正中・ドラフト段階の資料
└── index.html                   # 生成されたポータル画面（ハブページ）

```

## ファイル一覧と解説

* **`.github/workflows/generate-index.yml`**
* **役割**: インデックス自動更新パイプライン。
* **解説**: リポジトリへのPushをトリガーに起動し、後述の生成スクリプトを実行してポータルサイトを常に最新の状態に保ちます。


* **`generate_index.py`**
* **役割**: ポータル画面の自動生成エンジン。
* **解説**: `html_files` ディレクトリを再帰的にスキャンし、見つかったHTMLやPDFファイルを階層構造を保ったままリスト化し、`index.html` として書き出す責務を担います。


* **`html_files/`**
* **役割**: サービス運営に必要な全ドキュメントの実体格納。
* **解説**: 開業までの軌跡 や各種契約書類 など、事業遂行に不可欠な資産が整理されて保管されています。



## エントリーポイント

プログラムの実行および更新のフローは以下の通りです。

1. **資産の配置**: 開発者が `html_files` ディレクトリ内の適切なフォルダに資料（HTML/PDF等）を追加・更新してGitHubへPushします。
2. **自動ビルド**: GitHub Actions が Push を検知し、仮想環境上で `generate_index.py` を実行します。
3. **ポータル生成**: `generate_index.py` が全資産のパスとメタデータを解析し、ナビゲーションリンクを含む `index.html` をトップディレクトリに生成します。
4. **公開と閲覧**: 生成された `index.html` を通じて、ステークホルダーやユーザーは整理された各ドキュメントへ即座にアクセス可能となります。
